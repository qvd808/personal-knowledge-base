# Knowledge notes

Explanation notes: what a topic is, why the project settled on the approach it did, and
what that choice costs. A note here answers *can you tell me about this?* — it is not a
decision record and not a tutorial. Decision surveys of primary sources live in
`docs/research/`; agent operating docs live in `docs/agents/`.

Each note is ordered by its dependency graph, so a term is always defined before it is
used and a baseline is always taught before the deviation from it. The rules are in the
`knowledge-note` skill (`.agents/skills/knowledge-note/SKILL.md`), its section skeleton
and checklist in `NOTE-SHAPE.md` beside it.
