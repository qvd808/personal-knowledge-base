## Commands -- Version 0.9.5

```
apio system --lsftdi  // List all connected FTDI devices
```

```
apio build  // Build the current module with apio.ini present
```

```
apio build  // Build the current module with apio.ini present
```

```
apio verify  // Verify the current verilog file
```

```
apio sim  // Run the simulation for test bench
```

```
apio upload  // Upload the build
```
